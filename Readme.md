## Overview

This package contains the complete code and data to reproduce all tables and figures in the manuscript. The analysis examines whether government-sponsored R&D gives rise to clean-technology patents with above-average impact on subsequent technological development, using USPTO patents granted between 2005 and 2015.

## Requirements

**Software:** Stata 16 or later (see [Last tested](#last-tested) below for the exact version used).  
**Hardware:** Full replication takes approximately 45 minutes.  
**Ado-files:** All required packages are bundled in the `stata_packages/` folder and loaded automatically — no internet access or installation needed. Running `00a_packages_install.do` (switch `install_packages = 1`) will reinstall the latest versions from SSC, which may produce slightly different results.

## Replication instructions

1. **Get the code.** Clone the repository or download it as a ZIP and unpack it:
   ```
   git clone https://github.com/frarent/green_rd.git
   ```
2. **Open the Stata project.** Double-click `I_walk_the_line.stpr` (or open it from Stata via *Project > Open Project*). Be sure to do it while listening to [I walk the line by Johnny Cash](https://open.spotify.com/track/2bItf9pag16H6HtjLOqzSS?si=cb6a8a6303674a19) Stata will set the working directory to the repository root automatically — no path editing required.
3. **Set the run switches.** Open `scripts/00_master.do` and set the switches in the options block (lines 69–88) to `1` for the sections you wish to run. To reproduce everything, set all switches to `1` (and leave `install_packages = 0` unless you want to refresh the bundled packages).
4. **Run.** Execute `scripts/00_master.do`. All tables and figures are saved to `output/tables/` and `output/figures/` respectively.

### Switch options

| Switch | Default | What it runs |
|--------|---------|-------------|
| `install_packages` | 0 | Reinstalls all ado-files from SSC (overwrites bundled versions; may affect results) |
| `build_data` | 1 | Builds analysis datasets from raw CSVs |
| `tables_main` | 0 | Main manuscript tables (Tables 2–4) |
| `figures_main` | 0 | Main manuscript figures (Figures 1–2) |
| `tables_appendix` | 0 | Appendix tables (Table B1, Tables C2–C16) |
| `figures_appendix` | 0 | Appendix figures (Figures B1–B2, Figures C1–C4) |
| `housekeep` | 0 | Clears the `temp/` folder |
| `table_tex` | 0 | Output format: 0 = HTML, 1 = LaTeX (`booktabs fragment`) |

### Data sources

**PATSTAT (Autumn 2021).** Developed by the European Patent Office (EPO); covers patent details from multiple patent offices worldwide. Subscription required. https://www.epo.org/searching-for-patents/business/patstat.html

**3PFL database** (de Rassenfosse et al., 2019). Links patented inventions to US federal government contracts and grants, combining USPTO bulk data, Federal Procurement Database System, EPO PATSTAT and Clarivate Web of Science. Freely available at https://zenodo.org/record/3369582

**OECD Patent Quality Indicators (Spring 2021).** Citation-based indicators of the technological and economic value of USPTO and EPO patents at the document level. Documented in: Squicciarini, M., H. Dernis and C. Criscuolo (2013), "Measuring Patent Quality: Indicators of Technological and Economic Value", OECD Science, Technology and Industry Working Papers No. 2013/03. http://dx.doi.org/10.1787/5k4522wkw1r8-en

**PatentsView.** USPTO patent data with disambiguated inventor and assignee identities, used to construct the event-study sample (`db_event_study.dta`) and the shift-share IV instrument (`db_SSIV.dta`). PatentsView provides patent grant dates, citation linkages and assignee information needed to identify the timing of first citation from a government-supported patent and to construct the geographic-technology exposure shares underlying the shift-share instrument. Freely available at https://patentsview.org/download/data-download-tables
